# Runway (web demo)

Runway is a power-outage plan for one household: what runs out first, how long it has, and what to do first. Built with Flutter for the 2026 Congressional App Challenge (WA-01).

Live demo: https://pushkalkumar.github.io/runway-demo/

This repo holds only the compiled web build. Tap "See an example" on the first screen to load a sample home.
